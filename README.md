# Oh My Cake! – Bakery Website

## 1. Project Overview

Oh My Cake! is a bakery website developed to showcase a variety of delicious cakes, cupcakes and macarons. The website allows customers to explore available products, view cake descriptions and prices, add products to a shopping cart and make enquiries.

The website aims to provide users with an attractive, interactive and user-friendly online bakery experience.



## 2. Technologies Used

The following technologies and tools were used:

- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used to style the website, including colours, layouts, animations and transitions.
- **JavaScript:** Used to add interactive features and functionality.
- **Visual Studio Code:** Used as the development environment.
- **GitHub:** Used for version control and project management.

## 3. Website Pages

The website consists of five main pages:

### Home Page
- Introduces the Oh My Cake! bakery.
- Welcomes visitors to the website.
- Provides an Order Now button that directs customers to the cakes page.

### About Us Page
- Provides information about the bakery.
- Explains the history and background of Oh My Cake!
- Displays images and information about the business.

### Our Cakes Page
- Displays available cakes, cupcakes and macarons.
- Includes product images, descriptions and prices.
- Provides category filters: All, Cakes, Macarons and Cupcakes.
- Includes a search bar to help customers find products.
- Allows customers to enlarge product images using an image lightbox.
- Includes product details and quantity selection.
- Provides Add to Cart functionality.

### Enquiry Page
- Allows customers to submit enquiries.
- Includes a form for customer information and messages.
- Displays a confirmation popup after a valid form submission.

### Contact Page
- Provides contact information and trading hours.
- Includes customer reviews.
- Allows visitors to get in touch with the bakery.

## 4. JavaScript Features

JavaScript was implemented to make the website more interactive.

The features include:

- **Shopping Cart:** Allows customers to add selected cakes and other products to their cart.
- **Quantity Selection:** Allows customers to select the quantity of a product before adding it to the cart.
- **Category Filters:** Allows customers to view all products or select Cakes, Macarons or Cupcakes.
- **Search Functionality:** Allows customers to search for specific bakery products.
- **Image Lightbox:** Allows customers to click on cake images to view them in a larger format.
- **Form Confirmation Popups:** Displays confirmation messages after valid enquiry or contact form submissions.
- **Button Interactions:** Adds functionality to buttons such as Order Now and Add to Cart.
- **Animations and Transitions:** Improves the appearance of the website through interactive visual effects.

## 5. Search Engine Optimisation (SEO)

SEO techniques were added to improve the website's visibility and help search engines understand its content.

The SEO improvements include:

- Unique title tags for each webpage.
- Meta descriptions for all five pages.
- Meta keywords describing the bakery and its products.
- Author meta tags.
- Character encoding using UTF-8.
- Responsive viewport meta tags.
- Descriptive alternative text (alt text) for cake images.
