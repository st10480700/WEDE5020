**Oh My Cake!**

At OMC, we make cakes that look like craftwork and taste like dessert. Our mission is to add meaning to the lives of every child, couple, grandpa and grandma and best friend. We are here to make your birthday, anniversary, graduation or any milestones achieved very memorable. At OMC every cake tells a story which captures emotions, milestones and great memories. We believe that joy is best shared over something sweet. Our mission is to make cakes that are going to bring people together. 

The website was developed as part of a web development project to demonstrate the use of **HTML and CSS** to create a functional and visually appealing website

The Oh My Cake! website includes the following pages:

Home – Introduces customers to Oh My Cake! and provides an overview of the bakery.
About us – Provides information about the bakery and its history.
Our Cakes – Displays the different cakes and treats available.
Enquiry – Allows customers to submit an enquiry about cakes or orders.
Contact – Provides contact information for customers who want to get in touch.

The website was created using:

HTML5 – Used to structure the webpages.
CSS3 – Used to style and design the website.
Visual Studio Code – Used as the development environment.
Github – Used to store and manage the project.

The website uses a bakery-inspired design to create a welcoming and enjoyable experience for visitors. CSS is used to control:

* Colours
* Fonts
* Navigation
* Page layout
* Images
* Buttons
* Spacing
* Backgrounds
* Responsive design

The main purpose of Oh My Cake! is to give customers a way to:

1. Discover the bakery.
2. View available cakes.
3. Learn about the bakery's history.
4. Submit cake enquiries.
5. Find contact information.

These are the steps in which you will view the website:

1. Download or clone the project from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run the webpage using a browser or Live Server.
5. Use the navigation menu to move between the different pages.

Future versions of the website could include:

* An online ordering system.
* Online payments.
* A shopping cart.
* More cake categories.
* Improved mobile responsiveness.
